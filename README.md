# Sol Calendar

Mobile-first Android calendar/reminder app prototype.

## Source archive
Upload `SolCalendar-MVP-source.zip` to the repository root. The archive contains the Android project in a `SolCalendar/` directory.

## Build APK
After uploading the archive, open **Actions** and run **Build Sol Calendar APK**. The workflow extracts the project, builds a debug APK, and uploads it as a downloadable workflow artifact.

This is an early MVP scaffold, not a production release. Full bidirectional calendar reconciliation, conflict handling, recurrence, reboot alarm restoration, release signing, privacy policy, and device QA remain to be completed.
